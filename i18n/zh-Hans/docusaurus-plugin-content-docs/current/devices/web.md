---
title: "网页版的使用限制"
sidebar_position: 5
---

网页版运行在浏览器中，可用于受支持服务器的浏览和播放。使用前请了解它与已安装客户端的差异。

| 方面 | 当前限制 |
| --- | --- |
| 添加服务器 | 无局域网发现，无法在此客户端完成 Plex 浏览器授权。 |
| 下载 | 无正式音频下载和自动下载扫描。 |
| 存储 | 无原生端边听边存及缓存设置，存储分类有限。 |
| 音频 | 无 ReplayGain 和 DLNA 播放。 |
| 桌面集成 | 无桌面歌词、独立迷你播放窗口和全局快捷键。 |
| 扩展 | 无自定义接口设置和客户端网络代理设置。 |
| 会员 | 无购买界面。 |

浏览器自身的网络规则也会生效。HTTPS 页面可能无法访问 HTTP 服务器，服务器还需要允许网页版所需的请求。已安装客户端能连接，不代表浏览器能使用同一个地址连接。

需要下载、局域网设备连接或原生后台运行时，请选择[已安装客户端](../getting-started/install.md)。网页版登录失败时，[反馈问题](../help/feedback.md)请附上浏览器、站点地址和服务器连接方式。
