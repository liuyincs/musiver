| 功能 | 可用性 |
| --- | --- |
| 桌面/悬浮歌词 | Windows 壳；原生 macOS — 会员 |
| 迷你播放器 | Windows / macOS — 会员 |
| 全局播放快捷键 | 已安装的 Windows/Linux 客户端（非 Web） |
| 购买 | 桌面支付宝（Windows/Linux Tauri 壳） |

### 键盘（Windows / Linux 默认）

| 操作 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | Space |
| 上一首 / 下一首 | Ctrl + ← / → |
| 音量 | Ctrl + ↑ / ↓ |
| 收藏 | Ctrl + L |

全局快捷键额外加 Shift（如 Ctrl+Shift+Space），默认关闭。macOS 使用其菜单/系统快捷键。
