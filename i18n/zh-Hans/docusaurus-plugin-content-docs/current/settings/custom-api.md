title: "自定义接口"
sidebar_position: 2
---

自定义接口允许受支持的已安装客户端向额外服务请求封面或歌词。网页版不提供此设置。使用前，需要从接口提供方取得相应地址与配置说明。

1. 打开“设置 → 自定义接口”。
2. 按服务要求填写封面 URL、歌词 URL 或歌词确认 URL。服务要求认证时，再填写 Authorization 请求头。
3. 选择是否“优先使用服务器接口”，并配置可用的专辑、艺术家封面选项。
4. 正式使用前，先打开“测试接口”。

## 测试配置

填写歌曲标题、专辑和艺术家，或使用当前播放歌曲进行测试。检查状态码、响应内容，以及可用的封面或歌词预览。收到成功响应，不一定代表其中包含正确匹配。

测试失败时，请按接口提供方说明检查 URL 和认证信息。截图或公开反馈中不要包含 Authorization 值。来源配置成功后，可在[歌词搜索](../playback/lyrics.md)中选择。
