---
title: "网络代理"
sidebar_position: 3
---

只有连接需要经过代理时，才需要配置客户端网络代理。它与服务器的[连接线路](../servers/connections.md)是不同设置，网页版不提供这一客户端设置。

1. 在支持的已安装客户端中打开“设置 → 网络代理”。
2. 开启代理，使用支持的格式填写地址：`host:port`、`http://host:port` 或 `https://host:port`。
3. 激活服务器并配置可用线路后，选择“测试连接”。
4. 返回资料库，除了检查浏览，还应播放一首歌曲。

无法测试时，请先选择服务器并检查线路。本地回环目标会绕过代理，开启代理不代表所有本地请求都会经过代理服务。

开启后连接失败时，可以关闭代理再测试，以缩小问题范围。代理地址不能替代正确的音乐服务器地址，配置代理也不会自动解决服务器不可用的问题。
