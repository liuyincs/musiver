当前服务器支持时，会提供这些浏览方式。

## 流派与文件夹

打开“流派”，按服务器的流派标签浏览音乐。打开“文件夹”，按服务器提供的目录结构浏览。文件夹浏览不等于访问设备上的任意本地文件。

缺少流派或文件夹时，请检查服务器标签、扫描状态和账号权限。有些服务的 API 不提供这些浏览方式。

## 电台

打开“电台”，选择服务器提供的电台。电台是持续播放的音频流，不是有固定长度的歌曲，因此进度跳转、总时长及部分歌曲操作可能不适用。

普通歌曲可播放但某个电台失败时，请在服务器侧检查该电台的音频流。电台地址可能已失效，也可能使用了播放设备不支持的格式。睡眠定时可以停止电台，但不提供“播完当前曲”的选项。
