打开[下载页](/download)，选择对应平台的安装包（稳定版或测试版）。

| 设备 | 客户端 |
| --- | --- |
| iPhone / iPad | iOS / iPadOS |
| Mac | macOS |
| Apple TV | tvOS |
| Android 手机 / 平板 | Android |
| Android TV / Google TV | Android TV |
| 鸿蒙 | HarmonyOS |
| Windows | 桌面（setup.exe） |
| Linux | 桌面（AppImage） |
| 浏览器 | Web（自托管 Docker 镜像） |

有客户端**不等于**该平台具备全部功能。主用设备选型前请阅读 [Web 限制](../devices/web.md) 与 [电视](../devices/tv.md)。

![安装后的桌面欢迎页](/img/docs/getting-started/desktop-welcome.jpg)

### Web（Docker）

Web 客户端以 Docker 镜像发布（见应用仓库 `docker/web` 文档）。请自行部署；本站不提供公开在线演示。

安装完成后请继续[首次播放](first-play.md)。
