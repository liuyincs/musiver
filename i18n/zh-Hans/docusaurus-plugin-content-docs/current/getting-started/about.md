音流用于播放存放在服务器上的音频。服务器保存文件并提供资料库；音流登录服务器，列出账号有权访问的内容，再进行播放。

## 使用前需要准备

- 已运行的服务器，例如 Navidrome、Subsonic、Audio Station、Emby、Jellyfin、Plex 或 Audiobookshelf。
- 服务器地址和登录信息。Plex 使用浏览器授权。
- 设备到服务器的网络连接。家中可用的地址，离开家庭网络后不一定可用。

如果服务器由他人管理，请向管理员索取服务器类型、连接地址和账号。安装音流不会同时安装或配置服务器。

你可以浏览音乐、安排播放队列、使用服务器支持的歌单功能，并在支持下载的客户端保存音频。有声书与播客提供[专门的播放设置](../spoken-audio/playback.md)。

配置多个资料库或连接地址前，建议先了解[服务器、资料库与线路](../servers/concepts.md)。
