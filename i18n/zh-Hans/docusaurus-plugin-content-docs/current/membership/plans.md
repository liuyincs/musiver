音流采用**终身会员**（一次购买，含后续更新）。最多 **7** 台设备。公测期间客户端可能允许试用会员功能——以应用内提示为准。

![免费与会员分层](/img/docs/illustrations/membership-layers.svg)

## 免费

无需购买即可使用：

- 浏览资料库
- 在线播放全部歌曲
- 连接**一台**服务器

新版中 **DLNA 投屏免费**。

## 会员权益

权威来源：产品侧 `membership-benefits.md` 与各端 `MembershipBenefitCatalog`。下列中文名与应用内文案一致。

### 听感
- 均衡器
- 回放增益
- 音乐漫游（在队列中穿插相关歌曲）

### 歌词
- 沉浸式歌词
- 通知栏歌词
- 画中画歌词（iOS）
- 状态栏歌词
- 悬浮歌词

### 外观
- 黑胶封面
- 播放页动态背景
- 主题色
- 透明主题（含自定义背景图）
- 应用图标（iOS）

### 更多场景
- 多服务器（从**第二台**起）
- 离线下载
- 自动下载
- CarPlay（仅 iPhone）
- 快捷指令（仅 iOS）
- 迷你播放器（macOS / Windows）

### 平台说明（来自已确认矩阵）

| 权益 | 说明 |
| --- | --- |
| 桌面通知栏/悬浮歌词/迷你播放器 | 仅 Windows 壳 |
| 桌面播放页动态背景 | 桌面限免（不计入桌面会员目录） |
| tvOS 下载 | 不提供 |
| Android TV | 保留下载管理；不发起支付宝，请在手机购买后恢复 |
| Web | 无会员购买界面 |
| 透明主题 / 应用图标 / 画中画 / CarPlay | 另受系统/设备能力门控 |

**播放条歌词**（播放条上显示的歌词）为**免费**功能，不属于会员权益。
