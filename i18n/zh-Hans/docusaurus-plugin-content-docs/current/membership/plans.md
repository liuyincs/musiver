音流希望兼顾免费用户与会员用户的使用体验，因此对基础的浏览与播放功能不设任何限制。

![免费与会员分层](/img/docs/illustrations/zh-Hans/membership-layers.svg)

## 免费

无需购买即可使用：

- 浏览资料库
- 在线播放全部歌曲
- 连接一台服务器
- 多线路自动切换
- 睡眠定时
- 播放页歌词查看与搜索
- 播放条歌词
- 全局热键、自定义 API，以及平台提供的小组件

## 会员权益

以应用内实际会员权益为准，可同时在 7 台设备使用。

### 听感
- 均衡器
- 回放增益

### 歌词
- 沉浸式歌词
- 通知栏歌词
- 画中画歌词（iOS）
- 状态栏歌词
- 悬浮歌词

### 外观
- 黑胶封面
- 播放页动态背景
- 主题色
- 透明主题
- 应用图标（iOS）

### 更多场景
- 多服务器（从第二台起）
- 离线下载
- 自动下载
- CarPlay（仅 iPhone）
- 快捷指令（仅 iOS）
- 迷你播放器（macOS / Windows）
- DLNA 投屏
- 音乐漫游

### 平台说明

| 权益 | 说明 |
| --- | --- |
| 桌面悬浮歌词 / 迷你播放器 | 悬浮歌词支持 Windows 与 macOS（Linux 不支持）；迷你播放器支持 Windows / macOS |
| tvOS 下载 | 不提供 |
| Android TV | 不支持离线下载与自动下载；无应用内购买界面 — 请在手机购买后恢复 |
| Web | 无会员购买界面 |
| 透明主题 / 应用图标 / 画中画 / CarPlay | 还取决于系统与设备是否支持 |

另见[定价页](/pricing)。
