## 新增会员项

均衡器、音乐漫游、沉浸式歌词、通知栏歌词、黑胶封面、播放页动态背景（移动/TV）、主题色、透明主题、应用图标（iOS）。

## 不再作为会员项列出

旧对比表中有、新权益目录中没有：

- 自定义内容
- 长音频偏好（作为会员开关）
- 文件夹视图（媒体库模式）
- 重复歌曲检测（媒体库模式）

:::note
媒体库模式本身**尚未实现**，因此依赖该模式的文件夹视图/重复检测不可用。[待确认: 「自定义内容」是否会在后续回归。]
:::
