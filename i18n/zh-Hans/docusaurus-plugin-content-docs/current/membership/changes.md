## 旧版免费项去向

旧版里免费、用户常问「新版还在吗」的能力：

| 旧版免费项 | 新版情况 |
| --- | --- |
| 扫码同步（设备间同步数据） | 不能作为导入新版的路径 |
| 边听边存 | 设置 → 存储中的流媒体缓存（仍免费；与正式离线下载不同） |
| 全局热键 | 仍免费；已安装桌面端可用（默认关闭） |
| 增强手势 | 仍免费，各端常用手势照常可用 |
| 自定义 API | 仍免费；设置 → 自定义 API |
| 主屏幕小组件 | 仍免费；见[小组件](../devices/widgets.md) |

## 仍为会员（有调整）

| 项目 | 说明 |
| --- | --- |
| 离线下载 | 仍为会员 |
| 自动下载 | 旧版免费 → 新版为会员 |
| 多服务器 | 从第二台起仍需会员 |
| 主题 / 外观增强 | 旧版「主题切换」对应新版主题色、透明主题（会员） |
| 回放增益 | 仍为会员 |
| CarPlay / 快捷指令 / 迷你播放器 | 在对应平台仍为会员 |
| 桌面 / 状态栏 / 画中画歌词 | 在对应平台仍为会员（悬浮歌词支持 Windows 与 macOS） |

## 新增会员项

均衡器、音乐漫游、沉浸式歌词、通知栏歌词、黑胶封面、播放页动态背景（移动端 / 电视）、主题色、透明主题、应用图标（iOS）。

## 新版已移除

- 自定义内容 — 已移除，不会在音流中回归。

## 暂不可用（媒体库模式未实现）

以下旧版会员能力依赖媒体库模式，而该模式尚未实现：

- 文件夹视图（媒体库模式）
- 重复歌曲检测（媒体库模式）

旧版「长音频偏好」会员开关也不再提供；请改用[有声书与播客 / 资料库类型](../features/spoken-audio.md)相关流程。
