## 新版已移除

- **自定义内容** — 已移除，不会在 Musiver 中回归。

## 暂不可用（媒体库模式未实现）

以下旧版会员能力依赖**媒体库模式**，而该模式**尚未实现**：

- 文件夹视图（媒体库模式）
- 重复歌曲检测（媒体库模式）

旧版「长音频偏好」会员开关也不再提供；请改用[有声书与播客 / 资料库类型](../features/spoken-audio.md)相关流程。
