这三个概念分别对应不同的配置：

| 名称 | 含义 |
| --- | --- |
| 服务器 | 一份已保存的服务器连接及其账号。可以保存多个服务器，同一时间激活一个。 |
| 资料库 | 服务器提供的一组内容，例如音乐库或有声书库。一个服务器可以有多个资料库。 |
| 线路 | 访问同一个服务器的地址，例如家庭内网地址和外网地址。 |

“全部资料库”汇总当前服务器可用的资料库，不会合并不同服务器。设置资料库类型，或操作需要指定目标资料库时，应选择具体资料库。
