# 欢迎使用音流 Musiver

音流连接你自己的音乐服务器，让你在各设备上浏览和收听。它不托管曲库，也不提供流媒体订阅。

![音流多设备](/img/devices/musiver-devices.png)

## 支持平台

iOS · iPadOS · macOS · tvOS · Android · Android TV · Windows · Linux · HarmonyOS · Web（自托管 Docker）

Windows 与 Linux 采用 Tauri 跨平台方案，其余端均为原生实现。

## 支持的服务器

- 音乐：Navidrome、Subsonic、群晖 Audio Station
- 多媒体：Emby、Jellyfin、Plex
- 有声书：Audiobookshelf
- 实验性：Tag My Audio
