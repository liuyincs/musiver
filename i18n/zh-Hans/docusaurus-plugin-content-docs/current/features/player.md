## 是什么

播放条与完整播放页负责播控、队列、音质、均衡器、回放增益、睡眠定时与输出——其中包含免费的 DLNA 投屏。

## 怎么用

1. 开始播放后，从播放条打开完整播放页。
2. 用「下一首播放」/「加入队列」组织顺序；从其他列表直接开播可能替换队列。
3. 选择在线音质：无损，或 320 / 256 / 192 / 128 kbps 转码（取决于服务器）。
4. 在播放菜单或设置中打开均衡器、回放增益、音乐漫游。
5. 设置睡眠定时（可选：播完当前曲再停）。

![含均衡器的播放菜单](/img/docs/features/desktop-equalizer-menu.jpg)

## 睡眠定时

到点停播，或播完当前曲再停。支持的客户端可在播放相关控件里找到。

## DLNA 投屏

新版中 DLNA 免费。在播放条打开「投屏」，刷新设备列表，选择局域网中的 DLNA 设备；结束后切回本地输出。投屏时均衡器不可用。Web 版没有 DLNA。

![投屏 / DLNA](/img/docs/features/desktop-dlna-cast.jpg)
