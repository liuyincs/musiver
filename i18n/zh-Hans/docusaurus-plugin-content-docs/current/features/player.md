## 是什么

播放条与播放页负责播控、队列、音质、均衡器、回放增益、睡眠定时与输出（含免费 DLNA 投屏）。

## 怎么用

1. 开始播放后，从播放条打开播放页。
2. 用**下一首播放** / **加入队列**组织顺序；从其他列表直接开播可能替换队列。
3. 选择在线音质：无损或 320 / 256 / 192 / 128 kbps 转码（取决于服务器）。
4. 在播放页或设置中打开均衡器 / 回放增益 / 音乐漫游。
5. 设置睡眠定时（可选播完当前曲再停）。
6. DLNA：打开投屏/设备选择，选中渲染器，结束后切回本地输出。
