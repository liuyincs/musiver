## 是什么

面向 Audiobookshelf（及其他服务器的资料库类型）的有声书功能：书架 / 系列 / 作者浏览、继续收听、标记已播，以及记住的播放倍速。设好资料库类型后，才会显示章节、跳过等有声书专用控件。

## 怎么用

1. 添加 Audiobookshelf 服务器，或在媒体服务器上选择正确的资料库。
2. 设置[资料库类型](../servers/concepts.md)，以便显示有声书专用的播放控制。
3. 使用书架、继续收听，以及章节 / 跳过等控件（若提供）。
4. 调整倍速——音流可以记住，供之后使用。

## 平台 / 会员

有声书的浏览与播放不单独作为会员档位售卖。旧版「长音频偏好」付费开关已不在新版权益目录中。
