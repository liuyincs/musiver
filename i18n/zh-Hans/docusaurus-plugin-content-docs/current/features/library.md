## 是什么

按服务器能力浏览歌曲、专辑、艺术家、流派与电台。发现页可包含每日 / 随机推荐、最近添加、最多播放等。

![发现页](/img/docs/features/desktop-discover.jpg)

## 怎么用

1. 打开当前资料库的「歌曲」「专辑」或「艺术家」。
2. 使用该视图提供的排序 / 筛选。
3. 需要保留当前收听顺序时，优先用「下一首播放」/「加入队列」。
4. 打开艺术家页，查看服务器返回的专辑与曲目。

![艺术家页](/img/docs/features/desktop-artist.jpg)

## 收藏与历史

- 收藏：在列表或播放条点爱心；侧栏「收藏」可回放。
- 播放历史 / 最近播放：服务器或客户端提供时会显示（例如发现页的最近相关区块）。具体名称因服务器类型而异。

![收藏](/img/docs/features/desktop-favorites.jpg)

## 平台 / 会员

浏览与在线播放全部曲目免费。第二台服务器需要[会员](../membership/plans.md)。旧版媒体库模式下的文件夹视图尚未实现。
