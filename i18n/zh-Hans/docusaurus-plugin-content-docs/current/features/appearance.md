## 是什么

浅色/深色外观、主题色、透明主题、黑胶封面与播放页背景等选项。

## 怎么用

1. 打开**设置 → 外观** / **个性化**。
2. 选择外观模式与主题色。
3. 在播放偏好/个性化中启用黑胶封面或动态背景。
4. 在系统支持时启用透明主题（及自定义背景）。

## 平台 / 会员

主题色、透明主题、黑胶封面，以及（移动/TV 上的）播放页动态背景为会员权益。在**桌面**上，播放页动态背景为限免。应用图标切换仅 iOS（可用时）。
