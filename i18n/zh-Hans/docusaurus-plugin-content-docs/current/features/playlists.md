## 是什么

你可以在服务器上新建和编辑歌单，用 JSON 导入导出智能歌单规则，也可以通过 Tag My Audio 实验性地导入或搬运歌单。

![新建歌单](/img/docs/zh-Hans/features/desktop-playlist-editor.jpg)

## 怎么用

1. 从歌单菜单新建歌单；在曲目操作菜单中添加歌曲。
2. 在服务器允许时重命名或调整顺序。
3. 需要时从队列使用「保存为歌单」。
4. 智能规则 / JSON 请在支持的客户端使用智能歌单编辑器。
5. 跨服务器搬运目前走 [Tag My Audio 流程](../experimental/playlist-import-transfer.md)。

## 平台 / 会员

歌单增删改取决于服务器权限（本身不是会员功能）。电视 / CarPlay 不提供文件导出。跨服务器搬运仅限 Tag My Audio，且仍属实验性。
