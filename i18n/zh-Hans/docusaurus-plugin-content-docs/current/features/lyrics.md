## 是什么

歌词可来自音频文件、服务器或[自定义 API](../settings/custom-api.md)。支持逐词、沉浸式、各端覆盖层与内置歌词搜索。

## 怎么用

1. 打开播放页查看可用歌词。
2. 在播放页菜单中使用歌词搜索；预览候选并应用（保存在本地）。
3. 在歌词设置中调整字号/对齐等。
4. 在支持的客户端开启通知栏、状态栏、悬浮或画中画歌词。
