## 是什么

歌词可来自音频文件、服务器或[自定义 API](../settings/custom-api.md)。有时间轴时，逐词歌词会跟着进度一个字一个字地高亮。还支持沉浸式歌词，以及桌面、悬浮、状态栏、画中画等歌词显示方式，并内置歌词搜索。

## 怎么用

1. 打开完整播放页查看歌词（若有）。
2. 在播放菜单里搜索歌词，预览后应用（保存在本地）。
3. 在播放偏好 → 歌词中调整字体与对齐。
4. 在客户端提供时，开启通知栏、状态栏、悬浮、画中画等显示方式。

## 平台 / 会员

播放页内的歌词查看与搜索，以及播放条歌词，均为免费。沉浸式、通知栏、状态栏、悬浮、画中画歌词按[会员方案](../membership/plans.md)需要会员。
