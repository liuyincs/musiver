先区分具体情况：是无法连接服务器、登录被拒绝，还是登录后资料库为空。

| 现象 | 优先检查 |
| --- | --- |
| 无法连接服务器 | 地址、协议、端口、基础路径、当前网络，以及服务器是否运行。 |
| 认证失败 | 服务器类型、用户名和密码、账号状态，以及页面要求的额外验证。 |
| 只在家中可用 | 外网线路是否配置，以及离开家庭网络后能否访问。 |
| 已登录但没有内容 | 当前资料库、账号权限及服务器音频库扫描状态。 |
| 已安装客户端可用，网页版不可用 | 浏览器网络限制及[网页版限制](../devices/web.md)。 |

在同一设备、同一网络中打开服务器自带界面，有助于区分服务器或网络问题与音流自身的问题。

在“连接线路”中查看“当前连接”，不要假定始终使用第一条地址。刚配置过[代理](../settings/network-proxy.md)时，可以暂时关闭代理测试，判断问题是否与代理有关。

仍无法解决时，请[反馈问题](feedback.md)，附上服务器类型、应用版本、网络情况和准确错误信息。公开反馈时请遮盖密码、令牌和私密连接信息。
