### 快速排查

1. 打开应用内会员页——该端门控以它为准。
2. 按提示用邮箱 / 订单号 / App Store 恢复。
3. 旧版买家须先在**旧版**绑定邮箱。
4. Web 无法购买；Android TV 仅恢复。

恢复失败时，请记下确切错误、应用版本与平台后再[反馈](feedback.md)。
