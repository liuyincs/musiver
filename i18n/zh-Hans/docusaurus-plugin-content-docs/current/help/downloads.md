---
title: "下载与存储问题"
sidebar_position: 4
---

删除内容前，先打开“下载管理”检查任务状态。

| 问题 | 下一步 |
| --- | --- |
| 任务一直暂停 | 检查后台下载策略，以及当前网络是否满足要求。 |
| 下载失败 | 检查服务器连接和剩余空间，再重试失败任务。 |
| 列表中有歌曲却无法离线播放 | 确认下载已经完成，资料库条目不等于本地文件。 |
| 清理后离线内容消失 | 确认它来自播放缓存还是正式下载。 |
| 清理后占用未归零 | 当前播放所需文件可能因保护而保留。 |

只有某首歌曲反复失败时，先测试在线播放，再尝试下载另一首。失败与音质或转码格式有关时，请在反馈中附上所选设置。

不要一开始就反复清理全部存储，这可能删除需要离线收听的音频。请阅读[缓存与存储清理](../features/offline.md)，选择正确分类。

自动下载受后台运行和网络策略影响。网页版不支持正式下载，需要安装受支持客户端才能使用这一流程。
