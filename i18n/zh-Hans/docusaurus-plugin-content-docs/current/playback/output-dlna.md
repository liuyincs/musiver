使用耳机或蓝牙音箱时，请在设备的系统音频控制中选择输出。DLNA 则是音流与兼容网络播放设备之间的另一种连接方式。

## 使用 DLNA 播放

1. 将运行音流的设备与播放设备接入能够互相发现的网络。
2. 打开播放器的投屏或设备选择入口，选择发现的 DLNA 设备。
3. 播放一首歌曲，检查远端设备是否出声。
4. 通过远端音量控制调整播放设备音量，它与本机播放音量分别管理。
5. 选择本机播放即可返回当前设备，音流会停止远端播放会话。

播放设备必须能够访问音流提供的播放地址。能发现设备，不代表一定能传输音频。访客网络隔离或播放设备无法访问的服务器线路，都可能导致播放失败。

网页版不提供 DLNA 播放，投屏时也无法使用均衡器。为兼容设备，音频可能经过转码，因此投屏不保证原始格式或无损输出。
