在播放器中选择播放模式：

| 模式 | 用途 |
| --- | --- |
| 顺序播放 | 按队列顺序播放。 |
| 随机播放 | 打乱队列的播放顺序。 |
| 单曲循环 | 重复播放当前曲目。 |

另有独立的“循环播放”控制，用于决定是否循环整份列表。下一首与预期不符时，请同时检查播放模式和循环状态。

## 音乐漫游

音乐漫游可以在收听收藏时加入相似或随机歌曲。客户端提示需要会员时，需先解锁相应权益。

1. 在设置的播放分组中开启“音乐漫游”。
2. 打开收藏歌曲，从该列表发起“随机播放”。
3. 保持随机模式。换歌时，音流可能插入带有漫游标记的歌曲。

漫游不是让所有队列在结束后无限续播，而是作用于从收藏歌曲发起的随机队列。重新播放其他列表或更改播放模式，可能离开这一使用场景。
