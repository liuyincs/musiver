---
title: "界面、功能与平台变化"
sidebar_position: 1
---

新版音流在支持的平台上采用重新设计的客户端。熟悉的使用任务仍然存在，但入口位置和可用控件可能与旧版不同。

| 方面 | 使用时的变化 |
| --- | --- |
| 界面 | 按新版菜单与功能名称操作，旧截图可能已不对应。 |
| 服务器 | 增加 Audiobookshelf 选择，并提供专门的长音频使用流程。 |
| 资料库 | 通过资料库类型区分音乐、有声书和播客，并影响长音频播放行为。 |
| 设备 | 电视、CarPlay、桌面控制和网页版限制分别说明。 |
| 实验性功能 | Tag My Audio 单列邀请测试说明，并提供专属歌单流程。 |
| 已有购买 | 新版提供通过旧版已绑定邮箱恢复会员的方式。 |

一个客户端提供某项功能，不代表所有平台都有相同入口。同样，能够连接某个服务器，也不代表各服务支持相同的歌单或浏览操作。

本指南不承诺旧版配置、设置和缓存音频自动迁移。请按[旧用户开始使用新版](existing-users.md)准备新版，并在依赖它之前检查需要的内容。
