title: "Interface, feature, and platform changes"
sidebar_position: 1
---

The new Musiver uses redesigned clients across its supported platforms. Familiar tasks remain, but their location and available controls can differ from the previous app.

| Area | What to expect |
| --- | --- |
| Interface | Follow the new client's menus and task names; old screenshots may no longer match. |
| Servers | Audiobookshelf joins the supported server choices, with dedicated spoken-audio workflows. |
| Libraries | Library type helps distinguish music, audiobooks, and podcasts and controls long-audio behavior. |
| Devices | Use the platform guides for TV, CarPlay, desktop controls, and Web restrictions. |
| Experimental features | Tag My Audio has a separate invitation-only section and specialized playlist workflows. |
| Existing purchases | The new client provides email-based restoration for purchases linked in the previous app. |

Do not assume that a feature offered by one client has the same entry point on every platform. Likewise, an available server connection does not imply that every service supports the same playlist or browsing actions.

This guide does not claim automatic transfer of the old app's configuration, settings, or cached audio. Follow [getting started for existing users](existing-users.md) to prepare the new app and verify what you need before relying on it.
