Prepare the new app as a separate setup. Automatic import of the previous app's server configuration, preferences, downloads, and cache is not established for this version.

## Before switching

1. Keep a record of your server type, addresses, and account details.
2. If you purchased membership in the previous app, bind your email there before removing it.
3. Note settings you want to recreate and music you need offline.

## Set up the new app

1. Install Musiver and [add your server](../getting-started/first-play.md).
2. Check the library, play several tracks, and recreate the connection routes or preferences you need.
3. If you purchased membership in the previous app, open **Restore Purchase** and use the email bound there to complete verification.
4. Download required offline content again in the new client, then test without a network connection.

Server-side content should be checked using the same server account and library. A playlist stored on the server and a file downloaded by the old app are different kinds of data; seeing the playlist does not mean its audio has been transferred locally.

Keep the old setup until you have verified the new one meets your needs. Do not treat the previous app's device-transfer feature as a confirmed import path into this version.
