---
title: "Connect and play"
sidebar_position: 2
---

1. Open Musiver and accept the privacy notice when prompted.

![Privacy confirmation (desktop)](/img/docs/getting-started/desktop-privacy-modal.jpg)

2. Choose Add Server.

![Add Server type picker](/img/docs/getting-started/desktop-add-server.jpg)

3. Select the actual server type (for Navidrome, pick Navidrome even though it speaks Subsonic).
4. Enter address and credentials (or complete Plex browser OAuth).

![Navidrome login form](/img/docs/getting-started/desktop-navidrome-login.jpg)

5. Pick the library, open Discover or an album list, and play a track.

![Library home after login (Discover)](/img/docs/getting-started/desktop-library-home.jpg)

Server-specific notes: [Servers](../servers/concepts.md). If sign-in fails: [connection help](../help/connection.md). If audio will not start: [playback help](../help/playback.md).
