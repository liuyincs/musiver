---
title: "Connect and play your first song"
sidebar_position: 3
---

Before starting, make sure you can access your server from this device. If you do not know its type or address, ask the server administrator.

1. Open Musiver and select **Add Server**.
2. Choose the actual server type. For Navidrome, select Navidrome even though it also supports the Subsonic protocol.
3. Enter the connection information and sign in. See the [server instructions](../servers/concepts.md) for your service; Plex uses a browser authorization flow instead of the normal password form.
4. After authentication, review the server's libraries and choose the one to use. Enter the library when configuration is complete.
5. Open an album or the song list and select a song. The player should show its title and advance through the track.

Open the player from the playback bar to see playback controls and the queue. If the library is empty, check that you selected the right library and that your server account has access to it.

If sign-in fails, follow [connection troubleshooting](../help/connection.md). If browsing works but audio does not start, use [playback troubleshooting](../help/playback.md).
