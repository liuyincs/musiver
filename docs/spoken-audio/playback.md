---
title: "Chapters, playback progress, and speed"
sidebar_position: 3
---

For audiobook and podcast libraries, use long-audio settings to control how Musiver resumes and navigates content.

1. Open long-audio settings and enable resume playback if you want to continue from saved progress.
2. Choose whether the player buttons skip between tracks or jump backward and forward within the current audio.
3. Set the backward and forward jump durations separately.
4. Choose playback speed from the player's more menu. Enable remembering speed in long-audio settings if you want to retain that choice.

On HarmonyOS, open the chapter list when the player offers it and select a chapter to jump to it. On other clients, use the track list or progress bar. Chapter information depends on the server and content.

If you still see ordinary music behavior, check that you have selected the correct [library type](library-types.md) for the actual library.

Use the [sleep timer](../playback/sleep-timer.md) when listening before bed. Finishing the current track after the timer can mean finishing an entire long chapter, so choose that option deliberately.
