---
title: "Choosing a library type"
sidebar_position: 1
---

Library type tells Musiver how to treat its content. A music server may expose every collection as music even when one contains audiobooks.

1. Open **Manage Server → Libraries → Library Configuration**.
2. Find the actual library under **Library Types**.
3. Choose **Audiobook** or **Podcast** for spoken audio, or **Music** for ordinary music.
4. Switch to that specific library and check playback controls.

An explicit music choice can correct a library mistakenly treated as spoken audio. **Ringtone** is a classification label and does not itself enable long-audio playback behavior.

Configure real libraries, not the aggregate **All Libraries** view. For a server with several different kinds of content, select the audiobook or podcast library before using its specialized views.

Changing this setting does not create chapters, authors, series, or remote bookmarks that the server does not supply. Those features also depend on server capabilities. Continue with [spoken-audio playback](playback.md).
