Use this setup for Navidrome or a server offering the Subsonic API. Choose the matching server type in **Add Server**.

1. Enter the server's address, including the correct HTTP or HTTPS scheme and any required port or base path.
2. Enter the username and password supplied by your server administrator.
3. Sign in and review the available libraries.
4. Enter a library and play a song to confirm that both browsing and streaming work.

Use the server's base address, not a link to a song or an admin page. If the server lives below a path such as `/music`, keep that path in its configured connection.

Compatibility depends on the API implemented by your server. Sharing playlists, radio, folders, and other features may differ between Subsonic-compatible products. A missing action does not necessarily mean the connection failed.

For a connection that works at home but fails elsewhere, configure [local and remote connections](connections.md).

## Server setup

For server installation and administration, use the official guides: [Navidrome installation](https://www.navidrome.org/docs/installation/) and [Subsonic installation](https://www.subsonic.org/pages/installation.jsp). Choose the instructions for your server version.
