Choose **Audio Station** when connecting to a Synology server running Audio Station. Your DSM account must have permission to use the service and access its music.

1. Select **Add Server → Audio Station**.
2. Choose an address connection or **QuickConnect ID**.
3. For an address connection, enter the address, protocol, and port used by your NAS. For QuickConnect, enter its ID in the QuickConnect field.
4. Enter your username and password, then complete any additional verification requested by the sign-in screen.
5. Review the library and enter it to test playback.

An address and a QuickConnect ID are different inputs. Do not paste the full QuickConnect website URL into the ID field.

If authentication succeeds but the music list is empty, check Audio Station access and music indexing on the NAS. If only remote access fails, check the selected [connection](connections.md) and remote-access configuration.

## Server setup

For server installation and administration, use the official guides: [Audio Station help](https://kb.synology.com/en-global/DSM/help/AudioStation/AudioStation2_desc?version=6). Choose the instructions for your server version.
