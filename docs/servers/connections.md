title: "Local and remote connections"
sidebar_position: 8
---

Save multiple routes when the same server has different addresses at home and away. A route must lead to the same server and account, not a different music server.

1. Open **Manage Server → Routes → Connection Routes**.
2. Select **Add Route** and enter a complete address beginning with `http://` or `https://`. Include any required port and path.
3. Arrange the routes in your preferred order. On desktop, use the move controls or **Set as Primary**.
4. Check the **Current connection** label to see which route is actually in use.

Musiver considers availability and your preferred order when choosing a route. The primary route is a preference, not a command to use an unreachable address. Network changes and connection failures can cause a different route to be selected.

Test both situations: play a song on home Wi-Fi, then test from the network you use away from home. If remote access fails, verify that the remote address works from that device. Adding a route does not configure your router or make a private address accessible from the internet.

Desktop route menus also offer **Online Audio Quality** for that route. See [audio settings](../features/player.md).
