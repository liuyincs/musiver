These terms describe different parts of your setup:

| Term | Meaning |
| --- | --- |
| Server | One saved server connection and its account. You can save multiple servers, with one active at a time. |
| Library | A collection provided by a server, such as Music or Audiobooks. A server can have several libraries. |
| Connection | An address used to reach the same server, such as a home-network address or a remote address. |

**All libraries** combines the libraries available in that server. It does not combine different servers. Choose a specific library when configuring its type or when an operation needs a destination library.
