Choose **Audiobookshelf** to connect to its audiobook and podcast libraries.

1. Select **Add Server → Audiobookshelf**.
2. Enter your server address and sign-in details.
3. After authentication, select the library you want to use.
4. Open a book or episode and test playback.

For book collections, use the [shelf, series, and author views](../features/spoken-audio.md). Playback can include chapters, saved progress, speed control, and skip controls, depending on the content and client.

If content is treated as ordinary music, check the selected [library type](../features/spoken-audio.md). Choose a specific library when changing that setting.

Changing the library type in Musiver does not upload files or create a library on the server. Manage the actual books, episodes, and their metadata in Audiobookshelf.

## Server setup

For server installation and administration, use the official guides: [Audiobookshelf documentation](https://audiobookshelf.org/docs/documentation/introduction/). Choose the instructions for your server version.
