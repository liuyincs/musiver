Choose **Emby** or **Jellyfin** to match your server. Musiver uses its audio libraries; it is not a video player for the server's movie or TV collection.

1. Open **Add Server** and choose your service.
2. Enter the server address, including its port and base path where required.
3. Sign in with an account on that server.
4. Review the available audio libraries and select the one you want to use.
5. Open an album and play a track.

If no library appears, check that the server has an audio library and that your account can access it. An account that can sign in is not necessarily allowed to see every library.

Music metadata and covers come from the server. Correct missing or incorrect server metadata there, then refresh the view in Musiver.

If albums are visible but streaming fails, check [playback troubleshooting](../help/playback.md), including server transcoding and network access.

## Server setup

For server installation and administration, use the official guides: [Emby installation](https://emby.media/support/articles/Installation.html) and [Jellyfin installation](https://jellyfin.org/docs/general/installation/). Choose the instructions for your server version.
