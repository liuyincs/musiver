Plex sign-in uses authorization in a browser. The current Web app cannot complete the Plex authorization flow; use a supported installed client to set up the connection.

1. Select **Add Server → Plex** and start authorization.
2. Complete sign-in and authorization in the browser that opens.
3. Return to Musiver and select a server available to your Plex account.
4. Choose a Plex Home user if prompted. Enter a four-digit PIN only if that user has one.
5. Choose an audio library and test playback.

Your Plex account authorization and the selected Plex Home user serve different purposes. If a library is missing, check access for the selected user as well as availability of the server.

If authorization does not complete, keep the Musiver authorization screen open while finishing the browser step. If the server is listed but cannot be reached, check whether it is running and reachable from your current network.

## Server setup

For server installation and administration, use the official guides: [Plex installation](https://support.plex.tv/articles/200288586-installation/). Choose the instructions for your server version.
