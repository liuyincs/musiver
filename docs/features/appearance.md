## What it is

Light/dark appearance, accent color, transparent theme, vinyl cover, and player background options.

## How to use

1. Open **Settings → Appearance** / **Personalization**.
2. Pick appearance mode and accent color.
3. Enable vinyl cover or dynamic player background from player preferences / personalization.
4. Transparent theme (and custom background) where the OS supports it.

## Membership / platform

Accent color, transparent theme, vinyl cover, and (on mobile/TV) dynamic player background are membership benefits. On **desktop**, dynamic player background is free (limited free). App icon switching is iOS-only when available.
