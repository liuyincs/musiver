## What it is

Spoken-audio workflows for Audiobookshelf (and library-type handling on other servers): shelf / series / author browsing, resume, mark played, and remembered playback speed. Setting the library type shows the long-audio controls you need for chapters and skip.

## How to use

1. Add an Audiobookshelf server or select the correct library on a media server.
2. Set the [library type](../servers/concepts.md) so long-audio controls appear.
3. Use shelf views, continue listening, and chapter / skip controls when provided.
4. Adjust speed — Musiver can remember it for later sessions.
