## What it is

Manual downloads, auto-download rules, and stream cache for browsing previously cached items offline. The Web client cannot download — use the app or desktop client.

![Download manager](/img/docs/features/desktop-downloads.jpg)

## How to use

1. Choose Download on a track; watch progress in Downloads (pause / retry / clean on desktop).
2. Configure Auto Download (favorites, playlists, quality, network policy) on supported clients.
3. Download tracks before you travel: clearing cache can remove stream cache, but downloads stay.

## Membership / platform

Offline download and auto-download require membership. tvOS and Android TV do not support offline download or auto-download. Web has no offline downloads.
