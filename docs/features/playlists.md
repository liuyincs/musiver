## What it is

Create and edit server playlists, import or export smart playlist rules as JSON, and experimentally import or transfer playlists through Tag My Audio.

![New playlist](/img/docs/features/desktop-playlist-editor.jpg)

## How to use

1. Create a playlist from the playlists menu; add songs from a track’s action menu.
2. Rename or reorder where the server allows edits.
3. Use Save as Playlist from the queue when offered.
4. For smart rules / JSON, use the smart playlist editor in a supported client.
5. Cross-server transfer currently uses [Tag My Audio workflows](../experimental/playlist-import-transfer.md).

## Membership / platform

Playlist create/edit follows server permissions (not a membership feature by itself). TV / CarPlay do not offer file export. Import/transfer remains experimental.
