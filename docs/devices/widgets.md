Start playback in Musiver before testing system controls. The system can then show the current track and offer play/pause or track navigation through its media controls, depending on the platform.

## Home-screen widgets

iOS and Android include playback and lyric widgets. Add a Musiver widget through your system's home-screen widget picker, then open Musiver and start a song to check the displayed content.

Widget content follows the app's current playback state. Lyrics also require available lyric data. A widget is not a separate music player with its own server setup.

## If controls stop updating

Open Musiver and confirm that playback is active. Check the system permissions and background restrictions applied to the app. Widget refresh, lock-screen presentation, and background operation are controlled partly by the operating system; a lyric widget is not a promise of uninterrupted updates in every state.

For playback that stops when the screen locks, see [background playback troubleshooting](../help/playback.md).
