The Web client runs in the browser from a **self-hosted Docker** deployment. It shares UI code with desktop but is feature-incomplete versus native shells.

## Typical limitations

- No membership purchase UI
- No formal offline downloads
- No DLNA
- Background / media-session behavior depends on the browser

Use an installed client for purchases, downloads, LAN casting, and native overlays. Prefer desktop screenshots / testing for full feature docs.
