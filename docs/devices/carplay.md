title: "CarPlay"
sidebar_position: 3
---

CarPlay requires an iPhone client with the CarPlay membership feature available. Configure and test your server on the phone before connecting it to the vehicle.

1. Connect the iPhone to the vehicle using its normal CarPlay setup.
2. Open Musiver on the CarPlay display.
3. Use **Browse** to open available daily recommendations, favorites, playlists, or recently added content.
4. Choose a track to start playback, then use the Now Playing controls.

The **Settings** tab lets you switch the active server and library. CarPlay offers a focused browsing interface rather than the phone's full artist and configuration screens.

If Musiver asks you to configure a server or unlock membership, complete that step on the phone. A saved home-network address may be unreachable while driving, so prepare a working remote [connection](../servers/connections.md) or the audio you need in advance.

When network policy asks for permission to continue playback, choose the offered action. Cancelling or allowing the prompt to expire does not authorize network use.
