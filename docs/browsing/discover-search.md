Open **Discover** to browse the collections and recommendations offered for the current server. Available sections depend on the server's capabilities and your personalization settings.

## Find a specific item

1. Open search, enter a song, album, or artist name, then submit with the keyboard search key or Enter.
2. Switch between song, album, and artist results.
3. Open the result to play it or inspect its details.

Search uses the active server and selected library. If an item is missing, check that scope before changing the search term.

Some lists also provide a name filter. This narrows that list; it is different from searching the library. Audiobookshelf does not offer all of these music-list filters. Subsonic album filtering can use relevance ordering instead of the normal sort order.

Daily recommendations depend on the current service. A recommendation containing albums behaves differently from a list of songs, so its available actions can differ.
