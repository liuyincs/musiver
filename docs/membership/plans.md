Musiver uses a **lifetime membership** (one purchase, includes later updates). Up to **7 devices**. During public beta, clients may let you try membership features — check the in-app banner.

![Free vs membership](/img/docs/illustrations/membership-layers.svg)

## Free

These stay available without purchase:

- Browse the library
- Stream all songs online
- Connect **one** server

DLNA casting is **free** in the new version.

## Membership benefits

Authoritative catalog: product `membership-benefits.md` and each client’s `MembershipBenefitCatalog`. Grouped names below match in-app copy.

### Sound
- Equalizer
- ReplayGain
- Music roaming (related tracks woven into the queue)

### Lyrics
- Immersive lyrics
- Notification lyrics
- PiP lyrics (iOS)
- Status bar lyrics
- Desktop / floating lyrics

### Look
- Vinyl cover
- Player dynamic background
- Accent color
- Transparent theme (incl. custom background)
- App icon (iOS)

### Anywhere
- Multi-server (from the **second** server onward)
- Offline download
- Auto-download
- CarPlay (iPhone only)
- Shortcuts (iOS)
- Mini player (macOS / Windows)

### Platform notes (from confirmed matrix)

| Benefit | Notes |
| --- | --- |
| Desktop notification / floating lyrics / mini player | Windows shell |
| Desktop player dynamic background | Free on desktop (not in desktop member catalog) |
| tvOS downloads | Not offered |
| Android TV | Keeps download manager; no Alipay purchase UI — restore on phone |
| Web | No membership purchase UI |
| Transparent theme / app icon / PiP / CarPlay | Extra capability gates (OS / device) |

**Player bar lyrics** (lyrics shown in the playback bar) are **free**, not a membership feature.

See also the [pricing page](/pricing).
