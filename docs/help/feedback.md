---
title: "Reporting issues"
sidebar_position: 5
---

When reporting a problem through the project's issue tracker linked from the website, include enough detail to reproduce it:

- Musiver version, device, and operating-system version.
- Server type and version, selected library, and local or remote connection.
- Steps to reproduce, expected behavior, and what happened instead.
- Exact error text, approximate time, and whether another track or client works.

For a visual problem, include a screenshot with private details removed. Never post passwords, authorization tokens, or API keys.
