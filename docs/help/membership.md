### Quick checks

1. Open the in-app membership screen — it is authoritative for gates on that client.
2. Restore with email / order ID / App Store restore as offered.
3. Legacy buyers must bind email in the **old** app first.
4. Web cannot purchase; Android TV restores only.

If restore fails, note the exact error, app version, and platform before [reporting](feedback.md).
