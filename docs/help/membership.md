Check the [pricing page](/pricing) and the membership screen in your client for current plans and feature requirements. Platform-specific features still require a compatible device; membership does not add native features to the Web app.

## Restore access

1. Open the membership screen in an installed client.
2. Choose **Restore Purchase**.
3. Use the restoration method offered for your purchase. Complete the requested verification, then check the membership status again.

For a purchase from the previous version, first bind an email address in the previous app. In the new app, restore using that email address and its verification code. See [existing-user setup](../whats-changed/existing-users.md).

If restoration fails, check that the address matches the bound email and that verification completed. Record the error and app version before requesting help. Do not assume that entering any old order number will restore the purchase; use the method shown by the client.

The Web app has no purchase interface. Use an installed client for the purchase and restoration options it provides. This guide does not promise a feature on every platform just because it appears in a membership list.
