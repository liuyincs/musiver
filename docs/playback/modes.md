Choose the playback mode in the player:

| Mode | Use |
| --- | --- |
| Sequential | Follow the queue order. |
| Shuffle | Play the queue in a shuffled order. |
| Repeat one | Repeat the current track. |

The separate repeat-playback control determines whether playback loops through the list. Check both the selected mode and repeat state when the next song is unexpected.

## Music roaming

Music roaming can introduce similar or random songs while you listen to favorites. It requires membership where the client displays that requirement.

1. Enable **Music Roaming** in the playback section of settings.
2. Open your favorite songs and start **Shuffle** playback from that list.
3. Keep shuffle enabled. As tracks change, Musiver can insert roaming songs, identified in the queue.

Roaming does not mean every queue continues indefinitely after its last song. It applies to a shuffle queue started from favorite songs. Starting a different list or changing the playback mode can leave that context.
