# 官网营销：了解、比较和下载

覆盖的界面：home、download、pricing、changelog、navigation、navigation-desktop。

## 共通

### 信息结构

- home：品牌介绍、下载与快速开始操作、设备预览图、三项编号特性、会员说明与价格链接。
- download：标题与平台选择、发布渠道切换、版本元信息、变更列表、下载操作。
- pricing：标题、免费与会员方案、功能比较表、购买和恢复说明 FAQ、完整会员文档链接。
- changelog：标题、按版本分组的公共变更、各平台变更与下载链接。
- navigation / navigation-desktop：品牌、主页、文档、价格、下载、禁用的更新日志入口、语言菜单、GitHub、主题切换；页脚版权。

### 状态

状态 id 的语言前缀 en / zh-Hans 对应实际本地化路由。home、pricing、changelog 的 default 是完整静态内容。changelog 内公共变更缺省、平台空 changes 隐藏卡片、缺 downloadUrl 隐藏下载链接，当前历史记录同时呈现这些分支，无额外交互状态。

download 的 stable/beta × android/harmony/apple/windows/linux/web 分别保留选中状态。稳定版只有版本和更新时间；测试版默认只展开最新版本，更早的版本折叠成一行（版本号、日期、下载入口、展开控件），点开后展开变更列表；展开态是交互结果，不单独占截图状态。真实 JSON 有版本但 URL 为空时显示禁用的 Coming Soon；无版本时显示空状态；存在链接时显示可下载按钮。具体数据取 src/data/releases，新增空／错误／加载分支时同步扩展状态地图与截图断言；当前无异步加载和错误分支。

navigation 的 locale 是顶栏语言菜单展开；menu 是移动侧栏展开；menu-locale 是侧栏中的语言选择子菜单。navigation-desktop 仅 locale。菜单关闭时由各页面 default 覆盖。没有登录、首启引导或自定义确认弹层。pricing 的 FAQ 默认展开第一题，其余卡片收起，展开态是交互结果，不单独占截图状态。

### 产品约束

- 文档页面全部排除；指向文档的 CTA 和导航仍属于营销页（用户本次指定）。
- 双语和浅深主题均需保留；系统主题偏好可影响默认主题，截图明确设置主题（docusaurus.config.ts）。
- stable 下载地址为空是待发布业务状态；禁用按钮不是样式缺陷（src/data/releases/stable.json、src/pages/download.tsx）。
- 测试版只是最新版本默认展开、旧版本折叠（用户 2026-11-17 采纳方向性建议 D1）；折叠不删信息，版本号、日期、变更列表与下载入口都保留，展开后与原来一致。
- changelog 的历史版本文本是源码静态内容，顶部导航禁用但路由仍存在；评审不能自行更改版本事实（src/pages/changelog.tsx、docusaurus.config.ts、src/css/custom.css）。
- home 的设备图片展示音乐客户端，不意味着本仓库有原生客户端（src/pages/index.tsx、static/img/devices/musiver-devices.png）。
- 会员价格、平台限制、退款、邮箱恢复说明属于产品内容，保持语义，调整文案同步国际化键（src/pages/pricing.tsx、AGENTS.md）。
- 未发现独立背景配置或其他覆盖主题的用户选项；装饰参考线、编号特性属于现有视觉语言（src/pages/*.module.css）。
- navigation 右侧实际有主题切换按钮（docusaurus.config.ts 的 colorMode），蓝图 2026-11-17 补齐（此前漏写，desktop 评审员上报）。
- 平板侧栏的 GitHub 入口移到头部图标按钮（用户 2026-11-17 采纳方向性建议 D4）；手机侧栏仍留在列表内，左对齐。
- pricing 的 FAQ 改为可收拢卡片、默认展开第一题（用户采纳 D1/D3）；退款说明按渠道拆成分组条目（D1/D5）；比较表列头在桌面吸顶（D2）。

## 布局：desktop

平台：web-desktop。

- home：顶部横向导航；首屏左侧标题、说明与双 CTA，右侧设备图；下方特性标题、三列编号特性，最后会员说明与链接、页脚。
- download：导航下左右双栏，左标题与纵向平台按钮，右下载卡片；卡头左为平台及版本元信息、右为稳定／测试切换，下面变更列表和下载按钮。
- navigation-desktop：品牌和页面入口在左，语言、GitHub 与主题切换在右；语言选项在当前语言下方弹出。
- pricing：居中标题；方案卡片横向排列；下方比较表以功能、免费、会员三列展开（列头滚动时吸顶）；再下方 FAQ（可收拢卡片、默认展开第一题）和文档链接、页脚。
- changelog：标题后纵向版本时间线；版本标题和日期并排，公共变更占一行，平台卡片自动分列，底部横排可换行下载按钮。
- navigation-desktop：品牌和页面入口在左，语言与 GitHub 在右；语言选项在当前语言下方弹出。

族内允许的差异：无；只定义 Chromium 基准尺寸，不承诺其他浏览器像素一致。
